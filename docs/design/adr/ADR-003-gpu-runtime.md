# ADR-003：Vulkan＋CPU を同梱し、CUDA は追加パックにする
- 状態：承認 ／ 日付：2026-11-05 ／ 決定者：ユーザー
- 影響する ID：REQ-007, FR-001, FR-002, TBL-015

## 状況
知人の GPU は NVIDIA / AMD / Intel / なしとバラバラ。CUDA 版は llama 本体と cudart で 600MB 前後あり、全員に配ると更新のたびに重い。

## 決定
インストーラーには Vulkan 版と CPU 版だけを入れる。NVIDIA の人だけ、自分の GitHub Releases（`runtime-<ビルド番号>`）に置いた CUDA パックを sha256 確認つきで追加 DL する。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 全部同梱 | オフラインで完結 | インストーラーと毎回の更新が 600MB 以上重い | 更新の負担 |
| ggml-org の Releases から直接 DL | 自分のリリースが軽い | 版の固定と検証をアプリ側に持つ。配布元が変わると壊れる | ユーザーが自分の Releases を選んだ（R-09 次第で再検討） |
| CUDA のみ | 最速 | NVIDIA 以外で動かない | 知人の環境に合わない |

## 影響
- アプリの llama.cpp の版を上げるときは、先に runtime リリースを出す（R-02）
- cudart の再配布条件を公開前に確認する（R-09）
