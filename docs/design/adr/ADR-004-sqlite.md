# ADR-004：保存は SQLite にする
- 状態：承認（ドライバは better-sqlite3。D-55） ／ 日付：2026-11-05 ／ 決定者：ユーザー
- 影響する ID：REQ-006, REQ-009, 08 全体

## 状況
評価の結果をランどうしで比べ、推移を出す。スレッドの全文検索もしたい。DC-Designer は1件1つの JSON ファイルだった。

## 決定
SQLite（WAL・FTS5）の1ファイルに保存し、worker だけが読み書きする。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| JSON ファイル（DC-Designer と同じ） | ネイティブモジュール不要。中身を直接見られる | 集計・検索のたびに全件読む | 評価の集計が主目的 |

## 影響
- better-sqlite3 を選ぶ場合、asar の外に置き Electron 用にビルドする（R-08）
- 版上げ時に移行と1世代バックアップが要る（NFR-023）
