# ADR-005：読み取りは自動、書き込みとコマンドは承認、ワークスペース外は拒否
- 状態：承認 ／ 日付：2026-11-05 ／ 決定者：ユーザー
- 影響する ID：REQ-002, FR-009, FR-010, NFR-013

## 状況
9B モデルはツールの使い方を間違えやすい。知人の PC も壊したくないが、毎回の承認は面倒。

## 決定
ファイル系ツールのパスは実体に解決してワークスペース外を拒否する。読み取りは自動、書き込みとコマンドは承認制。スレッドごとに自動承認を ON にできる（外は ON でも拒否）。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 読み取りのみ（提案だけ） | 安全 | エージェントらしさがない | ユーザーが不採用 |
| 制限なし | 速い | 誤操作で PC を壊しうる | 同上 |
| コマンドをサンドボックスで動かす | コマンドも外に出られない | Windows では仕組みが重い | MVP では承認で代える（R-10） |

## 影響
- コマンドはワークスペース外にも影響しうるので、自動承認は利用者の明示操作だけで ON（R-10）
- 評価の agent ケースは使い捨てフォルダで自動承認
