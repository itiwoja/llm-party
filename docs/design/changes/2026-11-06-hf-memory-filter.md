# 変更記録：HF 検索を VRAM・RAM で絞れるようにし、取得ガイドを書く（2026-11-06）

> **3行で**：HF 検索に「VRAM まで（GB）」「RAM まで（GB）」を足し、目安メモリ（Q4_K_M）の列を出す ／ ファイル一覧にも目安を出す ／ 取り方と目安の表を `docs/guide/hf-models.md` に書いた

## 依頼と決定
| 項目 | 決定 | 根拠 |
|---|---|---|
| 絞り方 | 数字の上限（GB）を2つ。両方指定なら両方を満たす | 依頼の「VRAM・RAM でも絞る」。空欄は指定なし |
| 目安の基準 | Q4_K_M。`パラメータ数 × 0.61 byte × 1.1 + 1GB` | D-43（RAM 16GB・VRAM 8GB）、D-59（9B Q4_K_M は VRAM 8GB に収まる） |
| 文脈 | 既定 32K として見積もり、文脈長は使わない | D-22 |
| パラメータ数の分からないもの | 上限を入れたとき外す | 目安が出せないものを通すと絞り込みの意味がない |
| 件数 | 絞るときは HF から 100 件取ってから絞り、50 件に切る | HF はサイズで絞れない。50 件のままだと絞った後に残らない |
| 検索の起点 | 語・ジャンル・無検閲のどれもなくても、VRAM か RAM があれば一覧できる | 上限だけで探したい |
| ガイド | `docs/guide/hf-models.md` に置く（アプリ内には出さない） | 依頼の「書いてほしい」。アプリ内に出すなら別途決める |

## 変えないもの
- 既存の検索の結果（上限を入れないとき）。件数は従来どおり 50。
- ジャンル・無検閲の動き。
- DL の仕組み。

## 数字（確認待ち）
- 係数 0.61（Q4_K_M の byte/パラメータ）・1.1（文脈と作業分）・1GB（固定）。いずれも粗い見積もり。
- 件数の上限 100（絞るとき）。

## 未決
- 目安の係数は実際に動かして合わせていない。速さと実使用量は評価の画面で測って確かめる（D-56）。
