# 変更記録：音楽を生成できるようにする（2026-11-07）

> **3行で**：ACE-Step 1.5 をレシピで入れ、入力欄で音楽モデルを選ぶと曲ができる ／ エンジンは acestep.cpp の CLI（ADR-013）／ 8GB の GPU で 240 秒まで実機で確認した

## 依頼と決定
| 項目 | 決定 | 根拠 |
|---|---|---|
| エンジンの入手 | 作者の Windows 版（版 07abf07） | ユーザー回答 |
| 既定のモデル | LM 1.7B Q8・DiT turbo Q8・Qwen3-Embedding 0.6B Q8・VAE BF16（約 5.6GB） | ユーザー回答 |
| 曲の長さ | 既定 60 秒・上限 240 秒・下限 10 秒 | ユーザー回答（下限はモデルの制約） |
| 時間切れ | なし。止めるボタンで止める | ユーザー回答 |
| 入力欄 | 長さ・歌なし・歌詞。歌詞が空なら LM が作詞 | Claude 判断（見直し可） |
| 保存形式 | MP3 128kbps、`data/music/` | Claude 判断（見直し可） |
| 歌の言語 | かな・漢字があれば `ja`、なければ LM に任せる | Claude 判断（見直し可） |
| 長さ・歌なし・歌詞の欄 | 送信すると閉じ、生成が終わると戻る | ユーザー指示 |
| 生成中の表示 | ace-lm の思考をログから取り、チャットと同じ「思考」の折りたたみで出す。曲の履歴にも残す | ユーザー指示（表示の形は Claude 判断） |
