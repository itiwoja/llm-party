## 要点
- 土台は無彩色、差し色は主な操作と現在地にだけ使う。
- 文字は和文 Noto Sans JP、数字とコードは JetBrains Mono。
- 形は角丸 4px、影なし。
- 数字が主役になる場所は対話の画面にも置く（[下の表](#数字が主役になる場所)）。

## 詳細

### 3案の比較
| 案 | 作り | 主役 | 文字 | 形 | 差し色 |
|---|---|---|---|---|---|
| A 計測器（採用） | 細線で最小限に区切る | 大きな数字 | Noto Sans JP＋JetBrains Mono | 角丸 4px・影なし | ライム |
| B 静かな作業台 | 面の明暗で分ける | 会話の文章 | IBM Plex Sans JP＋JetBrains Mono | 角丸 10px・線なし | 青 |
| C 端末 | 1px の線で区切る | 等幅の文字 | BIZ UDゴシック＋JetBrains Mono | 角丸 2px | 琥珀 |

検索語は `developer tool AI desktop app dark technical`（variance 5）、`terminal monospace code editor developer`（variance 2）、`AI analytics evaluation data dashboard precise`（variance 8）。検索ツールの結果は Dark Mode (OLED)、Minimalism & Swiss Style、Brutalism と、組み合わせ「Developer Mono」（JetBrains Mono＋IBM Plex Sans）。案の名前と組み立ては、これをもとに作った定石（検索結果のページ構成は LP 向けのため使わない）。

### 選んだ案と変更点
- 案A をそのまま採用（R3 の確認で変更なし）。
- ライトの主ボタンは #4F6000 の塗り＋白文字（ライムは明るい背景と 1.23:1 のため。[D-14](00_brief.md#決定事項ログ)）。
- 3業種テスト：計測値を大きく出す組み方は分析ツールにも使えるため、このアプリだけの要素として文脈率・t/s・ツール n/40 の1行を入力欄の下に置いた。

### 数字が主役になる場所
| 画面 | 数字 |
|---|---|
| メイン | 文脈の使用率、トークン/秒、ツール呼び出しの回数（n/40）、コマンドの終了コード |
| ラン結果 | 正解率、平均点、平均トークン/秒、合計時間 |
| 比較・推移 | 正解率の差、改善と悪化の件数 |
| モデル・DL | ファイルサイズ、進捗率、残り時間 |

### 避けること
グラデーション、光る効果、影、差し色の多用、飾りの背景の帯、宇宙や回路のモチーフ。

### 参考アプリから
| 参考 | 残す要素 | 変える要素 | 理由 |
|---|---|---|---|
| Codex のアプリ | 無彩色＋差し色1色、会話の中央1列、小さな折りたたみ、横の差分 | 差し色と数字の見せ方を自分のものにする | ユーザー回答。そっくりな見た目を避ける |

参考の構成は公式の説明から：[Codex app](https://developers.openai.com/codex/app)、[Codex app features](https://developers.openai.com/codex/app/features.md)。実際の画面は撮っていないため、色や寸法の数値は参考にしていない。
