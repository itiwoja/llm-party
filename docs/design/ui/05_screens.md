## 要点
- 全画面で、段の差は文字の大きさと余白で付け、線は境だけに使う。
- 1画面の主ボタンは1つ。
- 待ちは数字（%・残り時間・n/total）で示す。
- 比較は左に折れ線、右に悪化が先頭の表。
- ウィンドウ幅ごとの変化は [07](07_responsive_a11y.md)。

- SEC と CMP：[01](01_ia.md#pg-001-メイン)。
- 段の付け方：会話は `--text-body`、数字の1行とプリセット選択は `--text-code`。セクションの間は `--space-6`、線はペインの境だけ。
- サイドバー（SEC-001-02、2026-11-06 変更）：見出しは「プロジェクト」「チャット」の2つだけで、同じ `--text-small`・`--color-muted-fg`。プロジェクト名は `--text-small`・`--color-fg`、選択中のプロジェクトは太さ 500 だけで示す（面は付けない）。スレッドは一段下げ（`--space-5`）。プロジェクト同士は `--space-3`、見出しの上は `--space-6` で区切る。線は引かない。プロジェクトが0件のときは何も出さない（空の案内は置かない。見出しの ＋ が追加の入口。2026-11-06 にユーザーの指示で CP-295 を削除）。
- サイドバーの視線の順：見出しの ＋ → プロジェクト名 → スレッド名。hover までアイコンを隠し、名前の並びだけで読めるようにする（現状の hover 表示を残す）。
- サイドバーの配置の意図：見出しを減らして、名前の並びを一本の流れにする（近接：プロジェクトの中身は段下げでまとめる）。
- 視線の順：入力欄 → 送信。入力・フォルダ・数字の1行・プリセット選択・思考の選択（対応するモデルだけ。D-76）・送信は1つの枠に収める。プリセット選択は枠の右下で送信の左に置き、会話の上には置かない。文脈長（32K）はプリセットの横ではなく円の隣に置く。承認待ちでは帯 → カード → 差分。
- 配置の意図：起動後すぐ打てるよう入力欄にフォーカスを置く（フィッツの法則：手数を減らす）。判断に要る差分をカードの右に出す（近接）。左端をそろえ、円と文脈長を隣に置いて、同じ情報を1つに見せる（近接）。狭い窓で1段に入らないときは、プリセット・思考・送信を右寄せのまま次の行へ折り返す。
- 状態：

  | 状態 | 表示 |
  |---|---|
  | 初期 | 上のワイヤー。入力欄にフォーカス |
  | 読み込み中 | 帯に CP-012。スレッドを開くときは行の高さを取った空の行 |
  | 生成中 | 送信が停止（CP-023、danger の secondary）に変わり、数字の1行で脈打つ（MOT-005）。主ボタンの扱いは承認待ちの間「承認」だけ |
  | 空 | 一覧に CP-030 |
  | エラー | 帯に CP-015〜CP-017、文脈満杯は入力欄の下に CP-050 と CP-051 |
  | 成功 | 会話に応答が残る。トーストは出さない |

  | SEC | 見出し | 本文 | ボタン | 文言 |
  |---|---|---|---|---|
  | SEC-001-01 | — | 1文 | 1つ | CP-012〜CP-018 |
