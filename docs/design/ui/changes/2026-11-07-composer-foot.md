## 直した理由
| 今の作り | 起きていたこと |
|---|---|
| 箱の余白 8px＋入力欄の左右の余白 8px、下の段は 8px のまま | 案内の文と `● 停止中` の左端が 12px ほどずれて見える |
| `32K` が円から離れ、プリセットの隣にある | 何の数字か読めない。空の円も意味が分からない |
| セレクトの ⌄ が左右に広がる | 文字と ⌄ が別々の部品に見える |
