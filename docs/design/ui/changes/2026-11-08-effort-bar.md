# 変更レポート：エフォートのバーを滑らかにし、色の塗りを付ける（2026-11-08）

> **3行で**：入力欄の思考の段階のバー（CMP-024）だけを直す ／ 丸は指についてきて、離すと段へ吸い付き、左から丸まで主色で塗る ／ 新しいトークンと文言はなし

## 🧭 判断してほしいこと
なし。

## 依頼と決定
| 項目 | 決定 | 根拠 |
|---|---|---|
| 範囲 | CMP-024 のカードの中のバーだけ | ユーザー依頼 |
| 配色 | 一色（`--color-primary` の塗りが伸びる） | ユーザー回答（見本で一色・信号・グラデーションを比較） |
| 動き | 指についてくる（離すと近い段へ吸い付く） | ユーザー回答（見本で「段から段へ滑る」と比較） |
| 動きの長さ | 段へ滑るのは `--duration-normal`（200ms）・`--ease-out` | Claude 判断（見本で了承。下の一覧で確認） |

選ばなかった案：信号（段で緑・黄・赤に変わる）、グラデーション（緑→黄→赤の帯）、段から段へ滑る（丸が段の位置にしか止まらない）。決定は [00 の D-38](../00_brief.md#決定事項ログ)、見本は `preview/effort-bar/index.html`。

## 直した理由
| 今の作り | 起きていたこと |
|---|---|
| つまみが1段ごとに進み、位置の変化に動きがない | 丸が低・中・高の間を飛ぶ |
| バーは灰色の地と点だけ | 今どこまで上げたかが長さで読めない |

## 見本と違うところ
- 塗りの中の目盛りは、見本の半透明の色ではなく `--color-on-primary`。新しいトークンを増やさないため。
- 目盛りの色は動かさず、すぐ切り替える。「transform と opacity だけ動かす」決まりを守るため。段へ滑っている間は、つまみが着くよりわずかに先に目盛りの色が変わる。
