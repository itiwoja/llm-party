# Hugging Face の OSS LLM を取る（VRAM・RAM の目安つき）

> **3行で**：チャットで動かすのは **GGUF** の **Q4_K_M** を選ぶ。VRAM に全部載れば速く、載らなければ RAM に一部載せて遅く動く。目安は下の表で、アプリの「Hugging Face を探す」欄で VRAM・RAM の上限を入れると、それに収まるものだけ出せる。

## 1. アプリから取る

1. モデル画面の「Hugging Face を探す」を開く。
2. ジャンルを「チャット」にし、語を入れて Enter（例：モデル名）。VRAM・RAM の欄に上限を入れると、その中に収まるものだけ出る。
3. 一覧から行を選ぶ。ファイル一覧に量子化（Q4_K_M など）・サイズ・目安メモリが出る。
4. 使いたいファイルの「DL する」を押す。途中で止まっても続きから再開する。
5. 終わると「モデル」に登録される。

- 「リポジトリ全体を DL」は複数ファイルがそろって動くモデル向け。普通は1ファイルで足りる。
- チャットで動かせるのは GGUF だけ。画像生成は単一の `.safetensors`（SD 1.x・SDXL など）が「画像モデル」として登録され、スレッドの「画像」から使える（FLUX・SD3 など複数ファイルのものは未対応）。それ以外（音声など）は「保存するだけ」になる。
- 画像生成には sd-server が要る。`LLM_PARTY_SD_BIN` に sd-server のパスを指定する。

## 2. 手で取る（アプリの外）

1. huggingface.co で、モデル名と「GGUF」を入れて検索する。
2. モデルのページの「Files and versions」で、`.gguf` のファイルを選んでダウンロードする。
3. アプリのモデル画面で「ファイルを登録」を押し、「参照」（元の場所を使う）か「コピー」（アプリの置き場へ写す）を選ぶ。

## 3. ゲート付きのモデル

Llama など、利用条件への同意が要るモデルは、HF のページで同意してから取る。アプリでは設定に HF のトークン（読み取り権限）を入れる。トークンなしで取ると「ゲート付きリポジトリ。設定で HF トークンが必要」と出る。

## 4. 量子化の選び方

| 種類 | 大きさ（8B の例） | 向いている人 |
|---|---|---|
| **Q4_K_M** | 約 5GB | 迷ったらこれ。品質と大きさのつり合いがよい |
| Q5_K_M・Q6_K | Q4 より少し大きい | 余裕があり、品質を少し上げたい |
| Q8_0 | 約 8.5GB（Q4 の約 1.7 倍） | 原本にほぼ近い品質がほしい |
| Q2・Q3 | Q4 より小さい | 容量が足りないときだけ。品質の落ちが目立つ |
| BF16・F16 | 約 16GB | 原本そのまま。VRAM 8GB では動かない |

IQ で始まる量子化は、同じ大きさで品質が良いことがある。ただし CPU では遅くなることがある。

## 5. VRAM・RAM の目安

目安は **Q4_K_M** の計算（パラメータ数 × 0.61 byte × 1.1 + 1GB）。文脈（会話の長さ）が長いほど増える。既定は 32K（[D-22](../design/00_overview.md)）。

| パラメータ数 | Q4_K_M の目安 | 例（VRAM の大きさ） |
|---|---|---|
| 1B | 約 1.7GB | どの GPU でも |
| 3B | 約 3.0GB | VRAM 4GB 以上 |
| 7〜8B | 約 5.7〜6.4GB | VRAM 8GB（余裕は少ない） |
| 9B | 約 7.0GB | VRAM 8GB（開発時の検証モデル。[D-59](../design/00_overview.md)） |
| 14B | 約 10.4GB | VRAM 12GB 以上 |
| 32B | 約 22.5GB | VRAM 24GB（文脈は短めに） |
| 70B | 約 48GB | VRAM 48GB 以上か、RAM に大きく載せる |

### 目安に沿った選び方

- **VRAM 8GB**：7〜9B の Q4_K_M。
- **VRAM 12〜16GB**：14B の Q4_K_M。
- **VRAM 24GB**：32B の Q4_K_M。文脈を長くすると入らなくなる。
- **GPU なし・CPU だけ（RAM 16GB）**：7〜8B の Q4_K_M。動くが遅い。

目安は粗い見積もりで、実際の使用量はモデルの構造と文脈長で変わる。速さは保証しない（[D-56](../design/00_overview.md)）。速さは評価の画面で測って確かめる。

### アプリでの絞り込み

- 「VRAM まで（GB）」：GPU に全部載るかの上限。
- 「RAM まで（GB）」：CPU で動かすときの上限。
- 両方入れたら、両方の上限を満たすものだけ出る。片方だけでも使える。
- パラメータ数の分からないモデルは、上限を入れたときに外れる。

## 6. 取るときに見ること

- **作者と配布元**：公式の組織の名前か、よく知られた作者か。同じ名前の改変版に注意する。
- **ライセンス**：一覧の「ライセンス」列を見る。商用に使えるかは、ライセンスの本文で確かめる。
- **無検閲のモデル**：断ることが少ない代わりに、出てくる内容の責任は使う人が負う。
- **ファイルの名前**：`-00001-of-0000N` の付いたファイルは分割。全部そろってから使う。
